# Skills gratis para Claude 🧠

Las skills y sistemas que aparecen en los videos de [@stgofigueroa](https://www.instagram.com/stgofigueroa/).
Todas son **gratis y de código abierto**. Aquí no se copian: cada link te lleva al repositorio original de su autor.

> ¿Qué es una skill? Una carpeta con instrucciones (`SKILL.md`) que le enseña a Claude a hacer un trabajo concreto: un PDF, un video, una auditoría, un plan.

## Cómo instalarlas

- **Claude Code:** `npx skills add <usuario>/<repositorio>` (por ejemplo `npx skills add anthropics/skills`), o copia la carpeta de la skill en `~/.claude/skills/`.
- **Plugins de Claude Code:** `/plugin marketplace add <usuario>/<repositorio>` y luego `/plugin install <nombre>`.
- **Claude.ai:** Configuración → Capacidades → Skills → sube la carpeta en un .zip.
